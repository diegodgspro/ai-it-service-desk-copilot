# DeskPilot v1.2.0

Release date: September 13, 2026.

Production: https://deskpilot.diegodgspro.workers.dev

## Enterprise RAG Foundation

This stable release adds authenticated D1 FTS5/BM25 lexical retrieval over an allowlisted, approved synthetic knowledge corpus. Ten reviewed documents produce 46 deterministic heading chunks with stable IDs, hashes, citations and metadata filters. Incident analysis and Intelligent Intake can present bounded evidence, while insufficient evidence returns an explicit abstention.

Ingestion is deterministic and idempotent: repeated generation is byte-stable across LF, CRLF, standalone CR and optional UTF-8 BOM input, and repeated remote ingestion preserves the same 10 documents, 46 chunks, IDs and hashes without duplicates. Migrations `0001` through `0004` are applied once, FTS synchronization is verified, and migrations plus the reviewed deterministic corpus remain the reconstruction source of truth.

## Validation and acceptance

Automated retrieval evaluation passed its 12-case synthetic baseline with Recall@1 0.90, Recall@3 1.00 and mean reciprocal rank 0.95. Metadata-filter correctness, approved-only enforcement, abstention accuracy and deterministic repeatability passed. TypeScript, production build/dry run, Worker/D1 tests, retrieval tests, artifact consistency, npm audit and GitHub Actions passed.

Production checks confirmed HTTP 200 for the shell, JavaScript and CSS; disabled local identity; HTTP 401 for anonymous, malformed-bearer, forged-identity and unauthenticated retrieval requests; the intended remote D1 binding; and 100% traffic on the recorded Worker version. Existing ticket and audit data remained intact.

The user separately accepted Auth0 production login, all nine existing incidents, relevant approved VPN and printer evidence, abstention for an irrelevant query, incident-state persistence, intake, audit and logout/login. This record deliberately excludes identities, tokens, permission maps, Auth0 configuration and the private D1 recovery bookmark.

## Authorization and safety boundaries

The public SPA shell contains no ticket data. The Worker validates Auth0 RS256 access tokens and independently applies server-owned read/write grants. Retrieval requires authentication and enforces approved-only content; retrieved text cannot change authorization or application policy. Automation remains simulated and human-controlled. No paid Cloudflare product, external AI service or paid fallback was enabled.

## Honest limitations

- Retrieval is lexical only; there are no semantic embeddings.
- No external LLM, Vectorize, Workers AI or AI Gateway is enabled.
- The reviewed corpus is English-only and the evaluation dataset is small and synthetic.
- Retrieved evidence supports investigation but does not confirm root cause.
- FTS5 virtual tables affect standard D1 export.
- Numbered migrations and deterministic ingestion remain the reconstruction source of truth.
