## Architecture and authorization

React/TypeScript assets and same-origin API are served by one Cloudflare Worker. Remote D1 persists tickets, current analyses and append-only audit. Auth0 uses Universal Login with PKCE and in-memory bearer tokens; the Worker validates RS256 signatures and required claims. Server-owned permissions independently authorize reads and writes. Anonymous API calls return 401; missing grants return 403. Mutations require the exact application origin and JSON.

Production disables the loopback identity. Cloudflare Access is intentionally not used. The public shell allows login but exposes no ticket records. Audit actors are private even though incidents are synthetic. No tokens, account identifiers or private authorization configuration belong in release records.

## Deployment and rollback overview

Follow the [deployment runbook](../cloudflare-deployment.md). Validate the branch, merge after CI passes, fast-forward clean main, inspect migrations and retrieve a private recovery bookmark. The guarded helper rebuilds with ignored production settings and deploys merged main. Verify public assets, API denial, disabled local identity, the remote binding and 100% traffic before tagging.

Rollback selects a recorded compatible prior Worker version; it does not reverse D1 changes. Prefer a corrective deployment for schema compatibility. Database restoration is destructive and not part of this release. No database export containing audit identities is committed. Workers Free, D1 Free and Auth0 Free only; no paid product, billing enrollment or paid fallback is authorized.

## Limitations and future increments

Automation remains simulated. No real ITSM connector, live PowerShell execution, production LLM or autonomous remediation is enabled. Analysis is a working hypothesis, never confirmation of cause. Python training data is not an independent evaluation set; live Ollama and standalone PowerShell execution are not release-validated.

The queue and visible audit history are bounded to 100 records; old analysis bodies are not archived. Session recovery depends on browser cookie policy. Free quotas constrain availability. Future work includes pagination, retention/private exports, accessibility, independent evaluation, a sandbox connector and an isolated public read-only demo. Optional narrative enrichment requires quota/security review. [Roadmap](../web-roadmap.md).
