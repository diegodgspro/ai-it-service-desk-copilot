# Endpoint: Windows 11

Portfolio knowledge article. Synthetic lab context; technician validation required.

## Symptoms
- windows 11 slow laptop disk full low space
- windows desktop freezing high cpu memory
- windows update error computer performance
- windows 11 crashes blue screen system
- computer running slow storage drive nearly full

## Working hypothesis
Low disk space, a recent change or resource pressure may be causing Windows performance issues.

## Troubleshooting
1. Capture symptoms, start time and recent software or Windows updates.
2. Check free disk space, Task Manager and relevant Event Viewer entries.
3. Compare the impact before and after the recent change; preserve diagnostic evidence.
4. Use approved cleanup options after checking user data and backup status.
5. Validate performance with the user; escalate repeat crashes or suspected hardware faults.

## Escalation and closure
Escalate when scope exceeds authorization, symptoms persist, or security indicators appear. Close only after user validation. Record evidence and outcome.
